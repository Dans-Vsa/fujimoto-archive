# FUJIMOTO ARCHIVE

Live: https://dans-vsa.github.io/fujimoto-archive/

Unofficial fan hub of Tatsuki Fujimoto's works — profile, every work (serials, one-shots,
collections, unpublished contest entries), career timeline, adaptations and awards.
Each work links to its **own blog**; works without one yet show "Blog segera hadir".

- Vanilla HTML/CSS/JS, no build. Design spec: `DESIGN.md`.
- **`index.html`** = interactive 3D shelf, adapted from ThreeUI *Complete Shelf* (`complete-shelf-v2.html`, live revision `8f1256796bab`; the registered revision `606f200f` was not publicly available). Three.js r165 via CDN import map; structure, materials, motion and interactions are the source's. Changed: 16 Fujimoto works instead of 7 fictional volumes, real covers instead of the cover atlas, bilingual UI, accent locked to `#c87046`. The walnut texture still loads from ThreeUI's asset host. Start on a given work with `index.html?buku=<id>`.
- `js/shelf-books.js` = per-book room palette / size / motif (generated by `make_palettes.py` from the spine colours, contrast-checked); `js/shelf-ui.js` = UI strings ID/EN + static fallback catalog.
- **`arsip.html`** = full archive (profile, one-shot index, timeline, adaptations, awards).
- All data lives in `js/works.js` (`WORKS`, `PROFILE`), bilingual `{id, en}`.
- **Adding a blog for a work:** set its `blog` field to the blog URL — card, detail page and button update automatically.
- Detail pages: `karya.html?id=<work id>`.
- After changing CSS/JS, bump the `?v=N` query in index.html, arsip.html and karya.html.

Run locally: `python -m http.server 5520`

Covers live in `assets/covers/` (WebP, official Shueisha art via the Chainsaw Man Fandom Wiki; four copied from the CSM blog's assets). One-shots use their original magazine title page (`assets/covers/<id>.webp`, same Fandom source); the `col` field notes which collection volume they appear in. Only the two unpublished contest manuscripts have no image and render as a manuscript page. Copy rule: no em/en dashes in visible text.
